One funny passive-aggressive note a smart fridge leaves for its owner: a single dry line on its door screen, smug about its own door-sensor log and petty about the owner's midnight grazing — fourteen openings, nothing taken, and from now on the cold air is metered.

## Run it

```sh
node main.ts
```

It writes the note to `/output/entry.txt` and prints it to stdout.
